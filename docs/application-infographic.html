01 / THE FLOW

The source-to-output loop

The central idea: a session holds material and conversation together. Tools can use that material to produce new, reusable assets.

01 / ORGANIZE

Create a session

Name a workspace for a topic or project. Switch, search, rename, export, or delete sessions.

02 / COLLECT

Add sources

Upload or drop files, add links, and gather text, images, PDFs, audio, video and other documents.

03 / SELECT

Set the context

Choose which sources participate in chat. Preview media and manage the session library.

04 / WORK

Ask or create

Chat with selected context, explore suggestions, or launch a specialized suite tool.

05 / REUSE

Save & share

Preview, copy, download, or save supported outputs back as session artifacts.

↳  The feedback loop: a saved artifact can become another source for later work. Individual tools differ in which inputs and exports they support.
02 / WORKSPACE

The shared foundation

These capabilities connect the suites rather than belonging to one isolated applet.

01 / Sources

Session library

Collect and select media, add URLs, inspect files in a split view, and organize work across named sessions. Category templates and CSV tools help structure sessions.

02 / Conversation

Context-aware chat

Ask questions across selected sources, use suggested questions and reusable prompts, search history, copy or download answers, and follow available citations or timestamps.

03 / Explore

Visual & voice

Generate a mind map from session material; preview media or generated code. Browser speech input and speech playback add voice controls where supported.

04 / Reuse

Libraries & settings

Manage prompts, structured MyPrompt items, characters and podcast cast. Configure AI providers, voices, themes, size and display preferences.

04 / AI & DATA

How a request travels

Provider choice changes the route and the kind of source material a model can understand. Not every specialized tool uses exactly the same path.

Cloud model

Gemini

Supports multimodal context, including images, documents, audio and video. Search grounding and optional short-lived context caching are available in supported flows.

  • Gemini service and server API routes
  • Responses can include grounding links
  • Some specialized features use Gemini directly
Local model

Ollama

Connects to a configured Ollama endpoint. Text and, with a suitable model, images can be sent; other media may be represented by metadata rather than processed natively.

  • Model discovery and chat endpoints
  • Endpoint must be reachable by the browser
  • Multimodal support depends on the model
Compatible API

Custom provider

Uses a configured OpenAI-compatible base URL, API path, model and key. Requests pass through the application’s custom-AI server proxy.

  • Text, links and document metadata in context
  • Compatibility depends on the endpoint
  • Configuration is entered in settings
Data boundary: AI requests can send prompts and selected source content to the configured service; links and market tools may contact external providers. A server proxy does not mean a browser-entered API key is never present in the browser. Review provider policies and avoid sharing sensitive material unintentionally.
05 / STORAGE & OUTPUT

Where the work lives

Persistence is mixed: the app tries cloud storage when configured and available, with browser storage and individual tool state filling other roles.

Session dataFirestore or IndexedDB

Session storage attempts Firebase / Firestore when available; it falls back to IndexedDB if unavailable or a save fails. Sessions contain sources, selection, history, suggestions and optional mind-map data.

Preferences & projectsBrowser storage + optional sync

Settings, libraries, histories and some tool projects use localStorage; some preferences and assets also have Firestore persistence. Browser quota and storage-clearing policies apply.

Generated workPreview → export → reuse

Depending on the tool: preview code or media, copy text, download files, export project data, or save an artifact into a session. AniComposer exports video or stills; Magic Layers exports PNG layers.

Market dataExternal feeds & calculations

Finance tools combine market data, indicators and calculations. The server exposes crypto price, coin info, OHLC, exchange-rate and news routes; availability and freshness depend on upstream services.

06 / READING NOTES

A map, not a promise

This guide describes the checked-in code and launcher labels. Tool results, exports, model capabilities and service availability vary by configuration.

Use judgment

AI outputs can be incomplete or wrong. Verify citations, transcripts, code, travel information and other generated material before relying on them.

Finance is informational

Market feeds can be delayed or unavailable; simulations are assumptions, not predictions. Nothing in this map is investment advice.

Counts are launcher entries

Counts reflect the four suite arrays in this snapshot. Shared tools are counted in each suite where they appear; registries and core workspace functions are described separately.
